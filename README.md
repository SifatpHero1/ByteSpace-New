# ByteSpace New

Landing page + Login/Signup (bonus), built with Next.js (App Router), TypeScript and Tailwind CSS v4.

## Run
```bash
npm install
npm run dev
```

## Structure
- `src/components/ui` – Button, Container, SectionHeading, CourseCard, AuthForm, Icons
- `src/components/layout` – Navbar, Footer
- `src/components/sections` – Hero, Explore, FeaturedCategories, Courses, CreatorTools, Testimonials, CreatorCTA
- `src/lib/constants.ts` – all page copy/data
- Design tokens (Shuttle Gray, Electric Lime, Persian Blue, fonts) live in `src/app/globals.css`

## Images
Replace files in `public/images/` with Figma exports (same names): `hero-man.png`, `creator-woman.png`, `course-1.jpg` … `course-6.jpg`.
